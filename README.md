# Projeto de Testes Manuais - SauceDemo

## Sobre o projeto

Este projeto de estudo independente tem como objetivo praticar testes funcionais manuais em uma aplicação web de demonstração, utilizando o SauceDemo.

## Objetivos

- Praticar a elaboração e execução de casos de teste.
- Verificar funcionalidades de login e carrinho de compras.
- Registrar resultados e evidências de execução.
- Praticar a documentação de comportamentos inesperados.

## Escopo dos testes

Foram elaborados e executados quatro casos de teste:

| ID | Cenário | Resultado |
|---|---|---|
| TC-LOGIN-001 | Login com credenciais válidas | Aprovado |
| TC-CART-001 | Adicionar produto ao carrinho | Aprovado |
| TC-CART-002 | Remover produto do carrinho | Aprovado |
| TC-CART-003 | Verificar a permanência do produto no carrinho após navegar entre páginas | Aprovado |

**Resumo:** 4 casos executados, 4 aprovados nos cenários definidos.

## Ferramentas utilizadas

- SauceDemo - aplicação web de demonstração.
- Microsoft Excel - documentação dos casos de teste e resultados.
- Microsoft Word - descrição do projeto, resumo de execução e relatório de ocorrência.

## Evidências e documentação

O projeto inclui casos de teste, resumo de execução, descrição do projeto e evidências de teste.

Foi documentado também um comportamento observado na conta de demonstração `problem_user`, que apresenta comportamentos problemáticos intencionais. Esse registro faz parte do exercício de estudo e não representa um defeito confirmado em um sistema de produção.

## Aprendizados

- Elaboração de casos de teste.
- Execução de testes funcionais manuais.
- Comparação entre resultados esperados e obtidos.
- Registro de evidências.
- Documentação de ocorrências.

## Observação

Este é um projeto de estudo independente, desenvolvido para fins de aprendizado e construção de portfólio. Não representa experiência profissional nem vínculo com a empresa responsável pelo SauceDemo.
